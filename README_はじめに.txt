にわの生きもの図鑑 — 最初の試作版
====================================

このフォルダーは、iPhone・パソコンで使い、家族と観察記録を共有するためのWebアプリのスターターです。

できること
- 生きもの写真の登録
- 観察日・名前・分類・庭の場所・メモの記録
- 名前・分類での検索
- 家族グループと招待コード
- AIによる生きもの候補の推定（サーバー側設定後）
- AI候補と人が確認した結果を区別

重要：まだ「完成して公開済みのアプリ」ではありません。
共有機能を動かすにはSupabaseの設定とWebホスティングが必要です。AI推定にはOpenAI APIの利用設定と別途API利用料が発生する場合があります。

おすすめの進め方（初心者向け）
1. パソコンでこのZIPを解凍します。
2. Supabaseで新しいプロジェクトを作ります。
3. SupabaseのSQL Editorで supabase/schema.sql の内容を実行します。
4. SupabaseのProject URLと anon / publishable keyをアプリの設定画面に入力します。
5. index.html / style.css / app.js / manifest.webmanifest / sw.js をHTTPS対応の静的ホスティングに配置します。
6. AI推定を使う場合は、supabase/functions/identify/index.ts をSupabase Edge Functionとしてデプロイし、OPENAI_API_KEYをFunction Secretに設定します。
7. まず自分のアカウントを作り、家族グループを作成します。家族は別アカウントを登録し、招待コードで参加します。

注意点
- Supabaseの「secret/service_role」キーやOpenAI APIキーをブラウザの設定画面に入力しないでください。
- AIは写真だけで種を確実に特定できるとは限りません。候補を確認してから記録し、未確定のまま保存する運用をおすすめします。
- iPhoneのホーム画面に追加するには、アプリをHTTPSのURLで公開してSafariで開き、共有メニューから「ホーム画面に追加」を選びます。
- 本スターターは開発用の出発点です。実際の公開前に、権限・データ保護・AIのエラー処理を確認してください。
